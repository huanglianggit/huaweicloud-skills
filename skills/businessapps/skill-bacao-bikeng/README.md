# 拔草避坑决策官

> 2026华为开发者大赛·小红书Skill创新赛 参赛作品

## 这是什么

给定一个商品（链接/成分表/参数/截图），输出一份**消费决策报告** + 一篇**可直接发到小红书的避坑笔记草稿**。

不给"买/不买"结论，给判断依据。

## 核心闭环

```
用户有购买纠结
   ↓ 用本 Skill 分析
得到决策报告 + 小红书笔记草稿
   ↓ 把笔记发到小红书
笔记里挂载本 Skill
   ↓ 读者看到笔记 → 一键装 Skill → 自己也能用
```

**产物即内容**：输出的小红书笔记草稿可直接发布，笔记里带本 Skill 的安装口令，形成"用 Skill → 发笔记 → 读者装 Skill"的传播闭环。

## 五个模块

| 模块 | 触发条件 | 输出 |
|---|---|---|
| M1 成分/参数解读 | 贴了成分表/参数表 | 逐项解读：含义、好坏、适用人群 |
| M2 平替思路 | 提到"平替/太贵/替代" | "盯哪3个核心参数" + 平替候选方向 |
| M3 避坑清单 | 问"有什么坑/智商税" 或只给品类 | 营销话术、智商税点、一句话识破 |
| M4 决策笔记生成 | M1/M2/M3/M5 任一已执行 | 小红书笔记草稿（可复制发布） |
| M5 多商品对比 | 贴了两个商品 或说"对比/VS/选哪个" | 对比表格 + 各自适合人群，不给"A完胜B"结论 |

## 使用方式

在 CodeArts / OfficeAce 对话框直接表达，例如：

```
帮我分析这个精华：烟酰胺5%、玻尿酸、苯氧乙醇，580元30ml，纠结要不要入
```

或：

```
扫地机器人有什么坑？智商税多吗
```

或：

```
SK-II神仙水太贵了，有没有平替思路
```

或：

```
帮我对比这两个精华：
A：烟酰胺5%、玻尿酸、苯氧乙醇，580元30ml
B：烟酰胺3%、玻尿酸、VC衍生物、无防腐剂，280元30ml
选哪个好
```

## 设计原则

1. **不给结论给框架**：中立可复用，一次分析翻车不会毁掉 Skill 信誉
2. **产物即内容**：输出天然是小红书内容，咬合小红书生态
3. **不依赖外部数据**：不爬虫、不调外部 API，知识沉淀在 markdown 规则文件，离线可跑
4. **品类可扩展**：规则文件按品类分块，新增品类不改逻辑

## 限制与边界

- 不给具体商品链接推荐（避免软文嫌疑）
- 涉及医疗/孕产/婴幼儿喂养的品类，输出附带"请咨询专业人士"提示
- 知识库覆盖 2026 年常见情况，需定期更新
