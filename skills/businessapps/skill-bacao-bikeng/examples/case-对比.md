# 测试案例：多商品对比（M5）

## 输入

```
帮我对比这两个精华：
A：烟酰胺5%、玻尿酸、苯氧乙醇，580元30ml
B：烟酰胺3%、玻尿酸、VC衍生物、无防腐剂，280元30ml
选哪个好
```

## 调度判断

- 识别品类：精华（护肤）
- 识别意图：贴了两个商品信息 + "对比/选哪个好" → 触发 M5
- 串联：M5 → M4
