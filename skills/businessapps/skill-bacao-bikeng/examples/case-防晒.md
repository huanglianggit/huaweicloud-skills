# 测试案例：防晒避坑

## 输入

```
防晒有什么坑？智商税多吗
```

## 调度判断

- 识别品类：防晒（护肤）
- 识别意图：只给品类 + 问"坑/智商税" → 触发 M3
- 串联：M3 → M4

## 期望输出

```
【决策报告】
- 品类：防晒（护肤）
- 避坑要点：
  · "SPF100+"：SPF超过50边际递减极小，SPF50已挡98%UVB，没必要追高
  · "纯物理防晒不泛白"：物理防晒必然泛白，"不泛白"是配方妥协或假宣传
  · "养肤防晒"：防晒剂+少量护肤成分，养肤有限，问养肤成分浓度多少
  · "防水8小时"：出汗/游泳后仍需补涂，"防水"≠不用补
  · 智商税点：
    - 防晒喷雾当面部防晒：吸入风险大，适合补涂身体
    - 带防晒值的粉底/隔离当主力防晒：用量达不到防晒标准
    - 高价防晒伞/防晒衣：UPF50+已足够，溢价是品牌税
    - 口服防晒丸：国内无批文，效果存疑
- 选购底线：
  · SPF30+/PA+++日常够用
  · 看是否含二苯酮-3（避雷）
  · 用量比选品更重要：2mg/cm²
```
