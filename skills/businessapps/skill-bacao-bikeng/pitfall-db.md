# 避坑清单知识库

> 本文件供 M3（避坑清单）模块调用。按品类分块，每块包含：营销话术、智商税点、一句话识破法。

---

## 通用识破原则

1. **绝对化宣传**：出现"最""100%""彻底""永久"等词，基本是违规宣传或夸大
2. **伪科学名词**：自造的"XX因子""XX科技"查不到学术出处，是营销包装
3. **成分党反向话术**：把基础成分包装成核心卖点（如把甘油说成"保湿黑科技"）
4. **恐吓营销**：制造焦虑再卖解药，"不用就烂脸/掉发/衰老"句式
5. **明星/网红背书**：看是否有实质成分/数据支撑，纯人设背书无意义

## 品类：精华（护肤）

### 营销话术识破

| 话术 | 真相 | 一句话识破 |
|---|---|---|
| "烟酰胺原液" | 单一成分难发挥，需复配 | "原液是原料桶思维，精华靠复配不靠堆单成分" |
| "医药级/药妆" | 国内无药妆分类，是营销词 | "国内只有妆字号和械字号，'药妆'是造词" |
| "浓度越高越好" | 超过刺激阈值反而烂脸 | "问有效区间是多少，不是越高越好" |
| "大牌同款成分" | 成分同名≠浓度同≠复配同 | "问浓度多少、复配什么，光说成分名没意义" |
| "无添加" | 不添加什么？没说就是话术 | "问具体无添加什么，写进配料表才算数" |
| "干细胞提取" | 护肤品用不了真干细胞 | "干细胞不能加进护肤品，这是概念蹭" |
| "基因科技" | 护肤品改不了基因 | "基因表达调控是医美级别，外涂做不到" |

### 智商税点

- ❌ **冻干粉/冻干精华**：多数是噱头，冻干工艺对稳定性有帮助，但不等于功效强
- ❌ **安瓶精华**：原是医药包装，护肤安瓶多数是高浓度刺激成分，敏感肌反烂脸
- ❌ **精华油叠加精华水**：油水不相溶，叠加使用效果不叠加，是凑单话术
- ❌ **"前导精华"概念**：本质就是精华，造个新词卖高价

### 选购避坑清单

1. 看全成分表（不是宣传成分），排名前5是核心
2. 主功效成分浓度是否标注（不标=可能很低）
3. 有无酒精/香精/争议防腐剂（看自己肤质）
4. 包装是否避光（维C/维A醇见光失活）
5. 价格/容量比是否合理（>30元/ml要质疑溢价来源）

## 品类：防晒（护肤）

### 营销话术识破

| 话术 | 真相 | 一句话识破 |
|---|---|---|
| "SPF100+" | SPF超过50边际递减极小 | "SPF50挡98%UVB，SPF100只多挡1%，没必要追高" |
| "纯物理防晒不泛白" | 物理防晒必然泛白，只是程度 | "物理防晒泛白是物理特性，'不泛白'是配方妥协或假宣传" |
| "养肤防晒" | 防晒剂+少量护肤成分，养肤有限 | "问养肤成分浓度多少，加0.1%也叫养肤" |
| "防水8小时" | 防水测试是实验室条件 | "出汗/游泳后还是要补涂，'防水'≠不用补" |
| "无化学防晒剂" | 物理防晒剂也有风险（纳米氧化锌吸入争议） | "物理≠绝对安全，看自己需求选" |

### 智商税点

- ❌ **防晒喷雾当面部防晒**：吸入风险大，且用量难控，喷雾更适合补涂身体
- ❌ **带防晒值的粉底/隔离当主力防晒**：用量达不到防晒标准（需2mg/cm²），防晒力不够
- ❌ **"防晒伞/防晒衣"高价款**：UPF50+已足够，几百上千的溢价是品牌税
- ❌ **口服防晒丸**：国内无批文，效果存疑，有肝肾负担

### 选购避坑清单

1. 看防晒剂组合（物理/化学/混合），选适合肤质的
2. SPF30+/PA+++是日常底线，不必追高
3. 看是否含二苯酮-3（避雷成分）
4. 肤感靠试用不靠宣传，油皮看是否含酒精
5. 用量比选品更重要：2mg/cm²，一张脸约1元硬币大小

## 品类：洗面奶（护肤）

### 营销话术识破

| 话术 | 真相 | 一句话识破 |
|---|---|---|
| "氨基酸洗面奶"卖150+ | 氨基酸表活原料不贵，高价是品牌税 | "问氨基酸表活排第几，排前3才算数，30-80元能买到一样的" |
| "美白洗面奶" | 洗面奶停留30秒就冲掉，美白成分来不及起效 | "洗面奶只负责清洁，美白交给精华/面霜" |
| "深层清洁" | 多是皂基配方，去脂猛，干皮/敏感肌烂脸 | "问是不是皂基，看成分有没有'XX酸+氢氧化钾'" |
| "毛孔级清洁" | 毛孔里的东西洗面奶洗不到，要靠水杨酸/泥膜 | "洗面奶进不了毛孔，'毛孔级'是造词" |
| "零残留" | 不可能零残留，是营销绝对化 | "问残留检测报告，'零残留'是违规宣传" |

### 智商税点

- ❌ **抗老/美白洗面奶**：停留时间太短，功效成分来不及起效，是噱头
- ❌ **高价氨基酸洗面奶**：氨基酸表活原料成本几块钱，150+元是品牌税
- ❌ **皂基洗面奶给干皮用**：去脂太猛，越洗越干，屏障受损
- ❌ **SLS/SLES洗面奶**：刺激性最强的表活，廉价洗面奶常用，敏感肌避雷

### 选购避坑清单

1. 看成分表前3位判断类型（氨基酸/皂基/硫酸盐）
2. 氨基酸型排前3才算真氨基酸洗面奶
3. 无SLS/SLES（避雷）
4. 敏感肌：无酒精无香精
5. 油皮可用皂基，干皮/敏感肌只选氨基酸
6. 别为"美白/抗老"洗面奶付溢价，洗面奶只管清洁

## 品类：扫地机器人（家电）

### 营销话术识破

| 话术 | 真相 | 一句话识破 |
|---|---|---|
| "AI避障" | 多数是红外+算法包装 | "问能识别哪些具体障碍物，说不清就是红外包装" |
| "全自动" | 可能只指自动回充 | "问自动集尘/洗拖/烘干哪些有，列功能别听'全'字" |
| "吸力8000Pa" | 宣传值≠实测值 | "看第三方测评实测值，宣传值普遍虚标20%+" |
| "LDS 4.0/5.0" | 版本号是营销造的 | "问具体升级了什么，光说版本号没意义" |
| "仿生手擦拖地" | 加压旋转就是加压旋转 | "'仿生'是包装词，看加压力度和转速" |
| "0死角清扫" | 物理上有边刷覆盖不到的区域 | "问边角覆盖率多少，'0死角'是理想值" |

### 智商税点

- ❌ **基站全能款**：自动集尘+洗拖+烘干+上下水，功能多但单点故障率高，维修贵
- ❌ **"自清洁"拖布**：洗不干净是常态，一周还得手洗一次，别指望真免维护
- ❌ **视频管家功能**：当监控用是噱头，画质差延迟高，不如买个真监控
- ❌ **高价配件耗材**：边刷/滤网/拖布耗材年成本200-500，买前算总持有成本

### 选购避坑清单

1. 看第三方测评实测吸力（不是宣传值）
2. 导航方式：LDS > 视觉（暗光翻车）
3. 续航看实测，宣传续航是空载最低档
4. 基站功能按需选，不必全要
5. 算耗材年成本，别只看机器价
6. 看售后网点密度，扫地机维修频率高

## 品类：奶粉（母婴）

> ⚠️ 涉及婴幼儿喂养，本清单仅作成分理解参考，实际选择请咨询儿科医生或营养师。

### 营销话术识破

| 话术 | 真相 | 一句话识破 |
|---|---|---|
| "最接近母乳" | 没有配方奶真正接近母乳 | "问接近哪些指标，母乳有200+种成分，配方奶模拟有限" |
| "进口奶源" | 奶源国≠生产国≠品牌国 | "看奶源/生产/品牌三个产地，别被'进口'一词糊弄" |
| "A2蛋白" | A2 β-酪蛋白是部分牛奶天然成分，非科技突破 | "A2是奶源特性不是工艺升级，看宝宝是否真不耐受A1" |
| "有机认证" | 有机是农法标准，不等于营养更好 | "有机管的是农药/饲料，不是营养成分，营养看配料表" |
| "添加益生菌" | 活菌数和存活率是关键 | "问活菌数多少、能否常温存活，加死菌不算数" |
| "脑黄金DHA" | DHA是标配不是加分 | "国标要求1段添加DHA，'添加'不是卖点" |

### 智商税点

- ❌ **高价"超高端"段**：400+元和200元段的核心成分差距小，溢价多在营销和包装
- ❌ **"羊奶比牛奶好"**：羊奶和牛奶蛋白结构差异有限，对牛奶蛋白过敏的宝宝仍可能对羊奶过敏
- ❌ **"防敏配方"普通段当防敏用**：真正的防敏是深度水解/氨基酸配方，普通段不能替代
- ❌ **海淘版本**：国行版和国外版配方不同（国标调整过），海淘版可能不符合国标

### 选购避坑清单

1. 看配料表全表，不是宣传成分
2. 1段：无香精/无蔗糖/无麦芽糊精/无葡萄糖浆
3. 看奶源/生产/品牌三个产地
4. 看段位是否匹配月龄
5. 看是否有国食注字（国内合规标识）
6. ⚠️ 换奶必须转奶过渡7-10天，不可直接换
7. ⚠️ 过敏/特殊体质宝宝请遵医嘱，本清单不替代专业建议
