## 标题模板库

### 通用句式（按场景选）

| 场景 | 模板 | 示例 |
|---|---|---|
| 价格纠结型 | `{价格}的{品类}扒完成分我悟了…{核心成分}到底值不值` | 580的精华扒完成分我悟了…烟酰胺5%到底值不值 |
| 避坑警示型 | `{品类}别再瞎买了！{N}个坑我交了学费总结的` | 扫地机器人别再瞎买了！6个坑我交了学费总结的 |
| 代价收获型 | `买{品类}我踩过的坑｜这{N}条血泪教训省下{钱/时间}` | 买扫地机器人我踩过的坑｜这6条血泪教训省下2000 |
| 平替挖掘型 | `{贵价商品}平替思路｜盯这3点就够了` | SK-II神仙水平替思路｜盯这3点就够了 |
| 成分科普型 | `{肤质/场景}+{成分}，{结论/疑问}` | 油皮烟酰胺精华，成分表一对比差距一目了然 |
| 对比拔草型 | `{价格}vs{价格}，{品类}到底差在哪` | 580vs180，精华到底差在哪 |
| 反向种草型 | `别买{品类}之前看这个｜{N}条避坑清单` | 别买扫地机器人之前看这个｜6条避坑清单 |
| 警告型 | `{人群}千万别{X}！血泪教训` | 敏感肌千万别跟风刷酸！血泪教训 |

### 标题规则
- 长度 18-28 字（小红书标题最佳长度）
- 含数字（提升点击率）
- 含情绪词（"悟了""别交""到底"）
- 不含绝对化词（违规风险）
- 不含"最""第一"等广告法敏感词
- **数字计数规则**：标题里的 N 必须等于内容里"营销话术 + 智商税点"的总条数，不能只算其中一类，否则货不对板

## 正文转写规则

### 把【决策报告】转成小红书体

**原始报告**：
```
- 烟酰胺5%：美白主力，浓度OK，油皮友好；敏感肌慎用
- 苯氧乙醇：争议防腐剂，敏感肌/孕妇慎用
- 性价比：19.3元/ml，中高端
```

**转写后**：
```
✅ 烟酰胺5%：美白主力，浓度OK，油皮冲
⚠️ 苯氧乙醇：争议防腐剂，敏感肌/孕妇绕道
💰 算下来19.3元/ml，中高端没跑了
```

### 符号映射
- ✅ 安全/有效/加分
- ⚠️ 有条件适用
- ❌ 风险/避雷
- 💧 基础配置
- 💰 价格/性价比
- 🌿 拔草/种草
- 🔍 看成分/看参数

### 对比笔记话术要点
- **开场**：用"纠结两款选哪个""拉出来一对比"引入对比场景
- **表格**：用 emoji 表格比纯 markdown 表格更小红书体
- **适合人群**：用"各自适合谁"代替"A更好"
- **结尾**：强调"不是A完胜B，是看你的需求"，呼应不给结论给框架原则
- **标签**：加 `#对比` 标签

## 话术调优原则

1. **口语化**：把"因此""综上所述"换成"所以""算下来"
2. **短句优先**：一句一个信息点，不超过20字
3. **emoji适度**：每段1-2个，不堆砌
4. **留白**：段落间空行，手机阅读友好
5. **不绝对化**：避免"一定""绝对""最"，用"建议""倾向""多数情况"（广告法+合规）
6. **带情绪但不极端**：可以"悟了""头秃""血泪""劝退"，不要"震惊""炸裂"
7. **第一人称**：用"我"不用"笔者"，用"姐妹们/家人们"不用"各位用户"

### 禁止词清单（公众号腔，必须替换）
| 禁止 | 替换为 |
|---|---|
| 值得注意的是 | （直接删，或换"重点来了"） |
| 综上所述 | 所以 |
| 因此 | 所以 |
| 笔者认为 | 我觉得 |
| 众所周知 | 大家都懂 |
| 在某种程度上 | 有点 |

### 强情绪词库（适度使用提升人感）
`真的` `巨` `绝绝子` `血泪` `后悔死了` `劝退` `悟了` `头秃` `差点` `还好`

### 标签规则（修正版）
- 总数 **3-5 个**（小红书最佳数量，超过8个反而堆砌降权）
- 1 个大流量标签（#拔草 #避坑 #成分党）
- 1-2 个品类标签
- 1 个场景/人群长尾标签
- 不用违规/敏感词标签

### 成分协同提示（成分党加分项）
涉及多成分时，顺带提协同/拮抗关系，比单夸一个成分更有深度：
- 烟酰胺+维C：不建议同用，刺激叠加
- 视黄醇+果酸：不建议同用，屏障风险
- 烟酰胺+透明质酸：协同友好，美白+保湿
- 维C+维E：协同抗氧化，1+1>2
