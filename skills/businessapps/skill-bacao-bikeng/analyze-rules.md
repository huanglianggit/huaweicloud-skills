# 成分/参数解读规则库

> 本文件供 M1（成分/参数解读）和 M2（平替思路）模块调用。按品类分块，每块包含：成分/参数字典、判断阈值、平替框架。

---

## 通用解读规则

### 解读优先级
1. **功效成分**（主角）：决定产品核心效果，看浓度和复配
2. **防腐/稳定剂**（配角）：看是否争议性，决定适用人群
3. **保湿/基质**（背景）：基础配置，不作为加分项
4. **香精/酒精**（风险项）：敏感肌/孕妇重点看

### 标注规则
- ✅ 安全/有效/加分
- ⚠️ 有条件适用（注明适用人群）
- ❌ 风险/争议/智商税
- 💧 基础配置（不算亮点）

### 浓度判断原则
- 给出"有效区间"和"刺激阈值"两个数
- 低于有效区间 → "浓度偏低，效果存疑"
- 在有效区间 → "浓度OK"
- 高于刺激阈值 → "浓度偏高，刺激性陡增"

## 品类：精华（护肤）

### 成分字典

| 成分 | 类别 | 解读 | 有效区间 | 刺激阈值 |
|---|---|---|---|---|
| 烟酰胺 | 功效-美白 | 美白主力，控油辅助；油皮/混油友好；敏感肌慎用（不耐受） | 2%-10% | >10% |
| 维C（抗坏血酸） | 功效-抗氧化 | 抗氧提亮，但易氧化失活；需避光保存；敏感肌刺激 | 5%-20% | >20% |
| 维A醇（视黄醇） | 功效-抗老 | 抗老金标准，但刺激性大；孕妇禁用；必须建立耐受 | 0.01%-1% | >1% |
| 玻尿酸（透明质酸） | 保湿-基质 | 安全温和全肤质可用，属基础配置 | 0.1%-2% | 几乎无 |
| 神经酰胺 | 保湿-修护 | 修护屏障利器，干皮/敏感肌友好，算加分项 | 0.5%-3% | 几乎无 |
| 多肽 | 功效-温和 | 温和抗老/修护，敏感肌可用，但效果慢 | 1%-10% | 几乎无 |

| 水杨酸（BHA） | 功效-疏通 | 疏通毛孔利器，油皮友好；干皮/敏感肌慎用 | 0.5%-2% | >2% |
| 积雪草提取物 | 功效-修护 | 修护屏障，敏感肌友好，痘肌修护 | - | 几乎无 |
| 泛醇（B5） | 功效-修护 | 修护保湿，温和全肤质，敏感肌友好 | 1%-5% | 几乎无 |
| 角鲨烷 | 保湿-亲肤 | 亲肤保湿，模拟皮脂，干皮友好 | - | 几乎无 |

| 传明酸（氨甲环酸） | 功效-美白 | 美白温和，淡化痘印，比烟酰胺温和 | 2%-5% | >5% |
| 熊果苷 | 功效-美白 | 美白温和，但需避光；部分人过敏 | 1%-7% | >7% |
| 维E（生育酚） | 功效-抗氧化 | 抗氧化温和，常配维C协同（1+1>2） | 0.5%-1% | 几乎无 |
| 苯氧乙醇 | 防腐 | 合规但争议，孕妇/敏感肌慎用；正常肤质无碍 | - | - |
| 尼泊金酯类 | 防腐 | 争议较大，部分酯类限用；敏感肌避开 | - | - |
| 酒精（乙醇） | 溶剂/促渗 | 挥发清凉，但干皮/敏感肌刺激；孕妇慎用 | - | 看排名 |
| 香精 | 体验 | 增香但致敏源，敏感肌/孕妇避开 | - | - |
| PEG-40 氢化蓖麻油 | 乳化剂 | 常见乳化剂/溶剂，相对温和，正常肤质无碍；重度敏感肌少数情况有刺激 | - | - |
| 甘油 | 保湿-基质 | 经典保湿剂，安全温和，属基础配置不算亮点 | - | - |
| 丁二醇 | 保湿-基质 | 常见保湿溶剂，温和，属基础配置 | - | - |
| 卡波姆 | 增稠剂 | 赋形剂，无功效无风险，中性存在 | - | - |
| 三乙醇胺 | 中和剂 | 调节pH用，合规但部分敏感肌有反应，正常肤质无碍 | - | - |
| EDTA二钠 | 螯合剂 | 稳定剂，微量无风险，属配方背景 | - | - |

### 平替框架（M2）

**盯这3个核心参数**：
1. 主功效成分浓度是否在有效区间（如烟酰胺≥3%）
2. 无酒精（排名前5出现即算有）
3. 无香精

**平替候选价位段**：150-300元/30ml（对标580元档，性价比提升50%+）

**平替判断话术**：
> "平替不是找同名成分堆浓度，是找'同功效路径+少风险项'。烟酰胺精华的平替，看'烟酰胺3-5% + 无酒精无香精 + 复配保湿'即可，不必死磕同一浓度。"

### 智商税点（联动 pitfall-db.md）
- "原液"概念：单一成分难发挥，复方才有意义
- "医药级/药妆"：国内无药妆分类，是营销词
- 浓度越高越好：超过刺激阈值反而烂脸

|---|---|---|---|
| 氧化锌 | 物理-防晒 | 全波段防护，温和，敏感肌/儿童友好；缺点是泛白 | 物理防晒主力 |
| 二氧化钛 | 物理-防晒 | UVB段防护，常配氧化锌用；泛白 | - |
| 奥克立林 | 化学-防晒 | UVB防护，光稳定性一般，会降解 | 常见但非优选 |
| 麦色滤MX | 化学-防晒 | UVA防护优秀，光稳定好，贵价防晒常用 | 优选成分 |

| 二苯酮-3 | 化学-防晒 | 争议较大，致敏率较高，孕妇避开 | 避雷成分 |
| 阿伏苯宗（Parsol 1789） | 化学-防晒 | UVA防护，但光稳定性差，需复配稳定剂 | 单用易降解 |
| 双-乙基己氧苯酚甲氧苯基三嗪（Tinosorb S） | 化学-防晒 | 广谱防护，光稳定好，分子大不渗透 | 优选成分 |
| Tinosorb M | 化学-防晒 | 广谱+物理特性，光稳定好 | 优选成分 |
| 乙基己基三嗪酮 | 化学-防晒 | UVB防护，光稳定好，欧系常用 | 优选 |
| 聚硅氧烷-15 | 化学-防晒 | UVB防护，光稳定好 | 常见 |
| 红没药醇 | 舒缓 | 舒缓抗炎，防晒常加，敏感肌友好 | 加分 |
| 泛醇（B5） | 修护 | 修护保湿，防晒常加，加分 | 加分 |
| 甘草酸二钾 | 舒缓 | 舒缓，防晒常加 | 加分 |

### 防晒核心参数（非成分）

| 参数 | 判断 |
|---|---|
| SPF值 | 日常30够用，户外50+；超过50+边际递减，不必追高 |
| PA值 | PA+++日常，PA++++户外；看+++以上即可 |
| 防水性 | 有标注"防水抗汗"才真防水；"抗水"≠"防水" |
| 肤感 | 看成分别看宣传：物理防晒泛白但温和，化学防晒清爽但可能刺激 |

### 平替框架（M2）

**盯这3个核心参数**：
1. SPF30+/PA+++（满足日常硬指标）
2. 防晒剂组合含 Tinosorb 或 麦色滤（UVA防护到位的标志）
3. 无二苯酮-3（避雷）

**平替候选价位段**：80-150元/50ml（对标400+元贵价防晒）

## 品类：洗面奶（护肤）

### 成分字典

| 成分 | 类别 | 解读 | 备注 |
|---|---|---|---|
| 椰油酰甘氨酸钾 | 表活-氨基酸 | 氨基酸表活主力，温和清洁，敏感肌友好 | 优选 |
| 月桂酰谷氨酸钠 | 表活-氨基酸 | 氨基酸表活，温和，常见复配 | 优选 |
| 肉豆蔻酸/月桂酸+氢氧化钾 | 表活-皂基 | 皂基配方，清洁力强但去脂力猛，干皮/敏感肌不友好 | 油皮可用 |
| 硫酸月桂酯（SLS/SLES） | 表活-硫酸盐 | 清洁力强但刺激性强，廉价洗面奶常用 | 避雷 |
| 甘油 | 保湿 | 降低去脂感，基础配置 | 标配 |
| 泛醇（B5） | 修护 | 修护保湿，加分 | 加分 |
| 烟酰胺 | 功效 | 洗面奶中浓度低，停留时间短，功效有限 | 别信功效宣传 |
| 水杨酸 | 功效 | 疏通毛孔，但洗面奶中停留短，效果有限 | 别期望太高 |
| 果酸 | 功效 | 同上，洗面奶中功效存疑 | 别期望太高 |
| 香精 | 体验 | 致敏源，敏感肌避开 | - |
| 酒精 | 溶剂 | 去脂感强但刺激，干皮避开 | - |

### 洗面奶核心判断

| 类型 | 标志成分 | 适合肤质 | 清洁力 |
|---|---|---|---|
| 氨基酸型 | 椰油酰甘氨酸钾、月桂酰谷氨酸钠 | 全肤质，敏感肌友好 | 中等，温和 |
| 皂基型 | 肉豆蔻酸+氢氧化钾 | 油皮/城墙皮 | 强，去脂猛 |
| 硫酸盐型（SLS） | 硫酸月桂酯 | 不推荐任何肤质 | 强，刺激 |

**判断方法**：看成分表前3位，有"XX酰XX氨酸钾/钠"=氨基酸；有"XX酸+氢氧化钾"=皂基；有"硫酸月桂酯"=硫酸盐（避雷）。

### 平替框架（M2）

**盯这3个核心参数**：
1. 氨基酸表活排前3（确认是氨基酸型不是皂基）
2. 无SLS/SLES（避雷）
3. 无酒精/无香精（敏感肌加分）

**平替候选价位段**：30-80元/100ml（对标150+元贵价洗面奶，氨基酸洗面奶平价好货多）

**平替判断话术**：
> "洗面奶是护肤品里平替最容易的品类，氨基酸表活就那几种，30-80元能买到成分和150+元几乎一样的。溢价主要在品牌和肤感调香，不在清洁力。"

### 智商税点
- "美白洗面奶"：洗面奶停留30秒就冲掉，美白成分来不及起效
- "抗老洗面奶"：同理，停留时间太短，抗老成分无效
- "氨基酸洗面奶"卖高价：氨基酸表活原料不贵，高价是品牌税
- 皂基包装成"深层清洁"：对干皮/敏感肌是烂脸神器

## 品类：扫地机器人（家电）

### 参数字典

| 参数 | 类别 | 解读 | 入门线 | 中端线 | 高端线 |
|---|---|---|---|---|---|
| 吸力(Pa) | 核心 | 决定清洁力，越大越好但边际递减 | 2000 | 4000 | 6000+ |
| 续航(min) | 核心 | 大户型关键，小户型60min够 | 60 | 90 | 120+ |
| 导航方式 | 核心 | LDS激光>视觉>dToF(部分)>随机 | 视觉 | LDS | LDS+dToF |
| 避障 | 加分 | AI避障>红外>无 | 无 | 红外 | AI |
| 自动集尘 | 加分 | 基站功能，省手 | 无 | 有 | 有 |
| 自动洗拖 | 加分 | 拖地机型关键 | 无 | 有 | 有+烘干 |
| 水箱容量(ml) | 体验 | 影响拖地续航 | 200 | 300 | 500+ |
| 噪音(dB) | 体验 | 越低越好，<70dB算安静 | 75 | 70 | <65 |

### 平替框架（M2）

**先问户型**（平替标准随户型变）：

| 户型 | 面积 | 续航底线 | 平替盯这3点 | 平替价位段 |
|---|---|---|---|---|
| 小户型 | <80㎡ | 60min | ①吸力≥4000Pa ②LDS导航 ③续航≥60min | 1000-1500元 |
| 中户型 | 80-120㎡ | 90min | ①吸力≥4000Pa ②LDS导航 ③续航≥90min | 1500-2000元 |
| 大户型 | 120㎡+ | 120min | ①吸力≥5000Pa ②LDS+dToF ③续航≥120min | 2000-3000元 |

**平替候选价位段原则**：必须低于用户产品价位，否则不叫平替叫同级。

**矛盾检测（M1执行时顺带做）**：
- 价位中高（>2000元）+ 续航入门（60min）→ 指出"这个价位配入门续航，性价比存疑，同价位能买到90min+"
- 价位中高 + 无LDS导航 → 指出"这个价位无LDS导航不合理，同价位LDS是标配"

**平替判断话术**：
> "扫地机器人的旗舰溢价主要在'自动集尘+自动洗拖+烘干'基站上，核心清洁力（吸力+导航）中端已经够。预算有限，砍基站留核心。"

### 智商税点
- "AI避障"噱头：很多是红外+算法包装，真AI避障看是否有具体识别品类宣传
- 吸力虚标：看是否有第三方测评，宣传值≠实测值
- "全自动"：可能只指自动回充，不包含自动集尘/洗拖，看具体功能列表

## 品类：奶粉（母婴）

> ⚠️ 涉及婴幼儿喂养，输出必须附带："个体差异大，奶粉选择请咨询儿科医生或营养师，本分析仅作成分理解参考。"

### 成分字典

| 成分 | 类别 | 解读 | 备注 |
|---|---|---|---|
| 乳糖 | 碳水 | 母乳主碳水，正常配方应有 | 标配 |
| 葡萄糖浆/玉米糖浆 | 碳水 | 乳糖不足时的替代，但营养价值低于乳糖 | 减分项 |
| 蔗糖 | 碳水 | 不应出现在配方奶中，增加嗜甜风险 | 避雷 |
| OPO结构脂 | 脂肪 | 模拟母乳脂肪结构，减少钙皂，算加分 | 优选 |
| 棕榈油 | 脂肪 | 常用但易形成钙皂，影响钙吸收 | 减分项 |
| DHA/ARA | 营养素 | 脑眼发育相关，国标要求1段添加 | 标配 |
| 乳铁蛋白 | 免疫 | 模拟母乳免疫成分，加分但非必需 | 加分 |
| 益生元（GOS/FOS） | 肠道 | 调节肠道，加分 | 加分 |
| 香精 | 体验 | 1段国标禁用，2/3段可用但无必要 | 避雷 |
| 麦芽糊精 | 填充 | 增加饱腹感但营养价值低，1段不应有 | 减分项 |

### 段位判断

| 段位 | 适用月龄 | 关注重点 |
|---|---|---|
| 1段 | 0-6月 | 严格模拟母乳，无香精无蔗糖无麦芽糊精 |
| 2段 | 6-12月 | 蛋白质略高，可接受部分调整 |
| 3段 | 1-3岁 | 营养补充性质，关注是否过度添加糖 |

### 平替框架（M2）

**盯这3个核心参数**：
1. 1段：无香精/无蔗糖/无麦芽糊精（硬指标）
2. OPO结构脂（脂肪质量标志）
3. 益生元+乳铁蛋白（加分项，非必需）

**平替候选价位段**：200-300元/800g（对标400+元超高端段，核心成分差距小）

**强制提示**：
> ⚠️ 奶粉选择个体差异极大（过敏、消化、口味），本框架仅帮助理解成分，实际选择请咨询儿科医生或营养师。换奶需转奶过渡，不可直接替换。

## 多商品对比框架（M5）

> M5 复用上方各品类的成分/参数字典，不另建知识库。本段定义对比逻辑。

### 对比维度选择规则

按品类自动选择对比维度：

| 品类类型 | 对比维度 | 判断依据 |
|---|---|---|
| 护肤（精华/防晒/洗面奶/面霜） | ①核心功效成分浓度 ②风险项（防腐剂/酒精/香精） ③性价比（元/ml） | 浓度查成分字典有效区间；风险项有无；价格÷容量 |
| 家电（扫地机器人） | ①核心参数（吸力/续航/导航） ②加分项（集尘/洗拖/避障） ③性价比（元/功能点数） | 参数查参数字典入门/中端/高端线；功能点=核心+加分项个数 |
| 母婴（奶粉） | ①核心成分（OPO/乳铁蛋白/益生元） ②风险项（香精/蔗糖/麦芽糊精） ③段位匹配 | 成分查成分字典；段位是否匹配用户宝宝月龄 |

### 对比判断规则

每个维度输出"商品A vs 商品B"的判断，用以下标签：

| 标签 | 含义 |
|---|---|
| A优 | 该维度商品A明显更好 |
| B优 | 该维度商品B明显更好 |
| 持平 | 两者差异不大 |
| 各有优劣 | A和B各有优势，不能简单判定 |

**禁止**：不给"A完胜B"或"B完胜A"的总体结论。最终只给"各自适合谁"。

### 适合人群推导规则

根据成分/参数差异推导各自适合人群：

| 差异类型 | 推导逻辑 |
|---|---|
| 浓度差异（护肤） | 浓度高→适合耐受皮/老手；浓度低→适合新手/敏感肌 |
| 风险项差异 | 无争议防腐剂/无酒精→适合敏感肌/孕妇；有→适合正常肤质 |
| 参数差异（家电） | 高参数→适合大户型/高要求；低参数→适合小户型/预算有限 |
| 价位差异 | 高价→适合预算充足/追求体验；低价→适合性价比优先 |
| 段位差异（奶粉） | 段位必须匹配宝宝月龄，段位不符直接排除 |

### 性价比对比规则

- 护肤：算 元/ml，低价位段不等于性价比高，需结合核心成分浓度综合判断
- 家电：算 元/功能点数（功能点=核心参数达标数+加分项数），功能点越多性价比越高
- 母婴：算 元/100g，结合核心成分（OPO+乳铁蛋白+益生元）有无综合判断

### 对比输出格式

```
【对比决策报告】
- 品类：xxx
- 对比维度：
  | 维度 | 商品A | 商品B | 判断 |
  |------|-------|-------|------|
  | 核心成分/参数 | ... | ... | A优/B优/持平/各有优劣 |
  | 风险项 | ... | ... | ... |
  | 性价比 | ...元/ml | ...元/ml | ... |
- 适合人群：
  · 商品A适合：...
  · 商品B适合：...
- 一句话：按你的需求选，不给"A完胜B"结论
```

### 对比边界处理

- **商品信息不对称**（A有成分表B只有参数）：指出"信息维度不一致，以下对比基于已有信息，建议补全后对比更准确"
- **跨品类对比**（如精华vs面霜）：拒绝，提示"跨品类对比意义不大，同品类对比才能看出差异"
- **三个及以上商品**：只对比前两个，提示"目前支持两个商品对比，已对比前两个，如需对比其他组合请分别提问"
